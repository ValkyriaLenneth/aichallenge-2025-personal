## 方案1核心原理详解

### 1. 时空域映射的数学基础

#### 1.1 空间域与时间域的转换关系

**空间域采样（CSV路径）**：
- 路径点按固定距离间隔采样：`s₀, s₁, s₂, ..., sₙ`
- 每个点包含：位置 `(x, y, z)` 和参考速度 `v_ref`
- 点间距通常为 1-2 米

**时间域预测（LSTM输出）**：
- 按固定时间间隔预测：`t₀, t₁, t₂, ..., t₅₀` (假设dt=0.1s，共5秒预测)
- 每个时刻输出速度：`v₀, v₁, v₂, ..., v₅₀`

**转换核心公式**：
```
空间距离 = ∫ v(t) dt ≈ Σ v_i × dt
```

### 1.2 映射算法详解

```python
def time_to_space_mapping(predicted_velocities, current_position, dt=0.1):
    """
    将时间域的速度预测转换为空间域的路径点
    
    输入：
    - predicted_velocities: [v₀, v₁, ..., v₄₉] 长度50的速度数组
    - current_position: 当前车辆位置在全局路径中的索引
    - dt: 时间步长
    
    输出：
    - space_velocity_map: {路径点索引: 预测速度} 的映射关系
    """
    
    # 1. 计算累积行驶距离
    cumulative_distances = [0]
    for i, velocity in enumerate(predicted_velocities):
        distance_increment = velocity * dt
        cumulative_distances.append(cumulative_distances[-1] + distance_increment)
    
    # 2. 将累积距离映射到全局路径的空间点
    space_velocity_map = {}
    for i, total_distance in enumerate(cumulative_distances[1:]):  # 跳过起始点
        # 在全局路径上找到距离当前位置total_distance的点
        target_space_index = find_path_point_at_distance(
            global_path, current_position, total_distance
        )
        if target_space_index is not None:
            space_velocity_map[target_space_index] = predicted_velocities[i]
    
    return space_velocity_map
```

### 2. 智能拼接策略

#### 2.1 分区域处理原理

将全局路径分为三个区域：

```
|----已过区域----|----LSTM覆盖区域----|----原始CSV区域----|
     (保持)           (LSTM预测)         (CSV参考速度)
```

**区域定义**：
- **已过区域**：车辆后方的路径点，保持原始状态
- **LSTM覆盖区域**：车辆前方200米范围，使用LSTM预测速度
- **原始CSV区域**：更远距离的路径点，保持CSV原始速度

#### 2.2 平滑过渡算法

为避免速度突变，在区域边界处进行平滑过渡：

```python
def smooth_velocity_transition(lstm_velocities, csv_velocities, transition_length=20):
    """
    在LSTM预测区域和CSV原始区域之间进行平滑过渡
    
    参数：
    - lstm_velocities: LSTM预测的速度序列
    - csv_velocities: CSV原始速度序列  
    - transition_length: 过渡区域长度（路径点数）
    """
    
    # 使用加权平均进行平滑过渡
    smoothed_velocities = []
    
    for i in range(transition_length):
        # 计算权重：从LSTM权重1逐渐过渡到CSV权重1
        lstm_weight = (transition_length - i) / transition_length
        csv_weight = i / transition_length
        
        # 加权混合
        mixed_velocity = lstm_weight * lstm_velocities[i] + csv_weight * csv_velocities[i]
        smoothed_velocities.append(mixed_velocity)
    
    return smoothed_velocities
```

### 3. 实时更新机制

#### 3.1 滑动窗口原理

```
时刻 t:   |--LSTM预测窗口(50步)--|
时刻 t+1:    |--LSTM预测窗口(50步)--|
时刻 t+2:       |--LSTM预测窗口(50步)--|
```

每个控制周期（0.1秒），预测窗口向前滑动，需要重新计算时空映射。

#### 3.2 增量更新算法

```python
class AdaptiveVelocityPlanner:
    def __init__(self):
        self.velocity_cache = {}  # 缓存已计算的速度映射
        self.last_update_position = None
        
    def update_velocity_mapping(self, current_position, lstm_predictions):
        """
        增量更新速度映射，避免重复计算
        """
        
        # 检查是否需要更新
        if self.should_update(current_position):
            # 清理过期的缓存数据
            self.cleanup_expired_cache(current_position)
            
            # 计算新的映射关系
            new_mapping = self.compute_new_mapping(current_position, lstm_predictions)
            
            # 更新缓存
            self.velocity_cache.update(new_mapping)
            self.last_update_position = current_position
            
        return self.get_current_trajectory()
```

### 4. 处理边界情况

#### 4.1 速度不连续问题

**问题**：LSTM预测的第一个速度值可能与当前实际速度差异较大

**解决方案**：
```python
def ensure_velocity_continuity(current_velocity, predicted_velocities, max_accel=2.0, dt=0.1):
    """
    确保速度序列的物理可行性
    """
    corrected_velocities = [current_velocity]  # 起始速度为当前实际速度
    
    for i, predicted_v in enumerate(predicted_velocities):
        last_v = corrected_velocities[-1]
        
        # 计算允许的最大速度变化
        max_delta_v = max_accel * dt
        
        # 限制速度变化率
        if abs(predicted_v - last_v) > max_delta_v:
            if predicted_v > last_v:
                corrected_v = last_v + max_delta_v
            else:
                corrected_v = last_v - max_delta_v
        else:
            corrected_v = predicted_v
            
        corrected_velocities.append(corrected_v)
    
    return corrected_velocities[1:]  # 返回除当前速度外的预测序列
```

#### 4.2 路径终点处理

**问题**：当车辆接近路径终点时，LSTM预测可能超出路径范围

**解决方案**：
```python
def handle_path_boundary(global_path, current_position, predicted_mapping):
    """
    处理路径边界情况
    """
    max_path_index = len(global_path) - 1
    
    # 过滤超出路径范围的映射
    valid_mapping = {
        idx: velocity for idx, velocity in predicted_mapping.items()
        if idx <= max_path_index
    }
    
    # 如果预测窗口超出路径，在终点附近进行减速处理
    if max(predicted_mapping.keys()) > max_path_index:
        # 计算到终点的距离
        distance_to_end = calculate_distance_to_path_end(current_position, global_path)
        
        # 应用减速策略
        if distance_to_end < 50:  # 距离终点50米内开始减速
            apply_deceleration_strategy(valid_mapping, distance_to_end)
    
    return valid_mapping
```

```python
class RealTimePlanner:
    def __init__(self):
        self.computation_budget = 0.05  # 50ms计算预算
        self.fallback_strategy = "use_csv_velocity"
        
    def plan_with_timeout(self, lstm_predictions):
        """
        带超时保护的规划算法
        """
        start_time = time.time()
        
        try:
            # 执行主要的时空映射算法
            result = self.main_planning_algorithm(lstm_predictions)
            
            # 检查计算时间
            if time.time() - start_time > self.computation_budget:
                self.get_logger().warn("Planning computation exceeded budget, consider optimization")
            
            return result
            
        except Exception as e:
            # 降级到备用策略
            self.get_logger().error(f"Planning failed: {e}, using fallback strategy")
            return self.execute_fallback_strategy()
```
