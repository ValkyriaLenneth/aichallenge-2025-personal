# 终极目标
在Autoware自动驾驶系统中，使用自己训练的NN planner来替代原始的planner。
以达到更高的圈速

# 模型的选择
模仿学习+强化学习
## 模仿学习
基础模型： LSTM
由于planner天然属于时序任务，因此使用简单的LSTM模型就可以满足需求。
而且考虑到实时性的问题，模型可能并不需要很复杂
## 强化学习
学习算法： SAC

# 一阶段开发： 固定路径，只学习速度
原始的planner只读取预设好的csv格式的路径。然后发布所有路径。
为了降低开发难度，暂时只让lstm输出目标速度，而不是完整的坐标+速度。

# 奖励函数设计
我们希望nn planner能达到以下目的：
1. 保持车道在给定的路径中
2. 在直道加速，在进入弯道之前减速，保持在弯心，然后过弯心开始加速。这样能达到最快圈速。
3. 提高圈速，减少用时
4. 避免撞墙。
